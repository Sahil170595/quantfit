# Fictional whole-target saved adjudication screen

This is aggregate evidence for the **unreleased 0.48.0 source candidate**, stacked
on unreleased 0.47.0. Public installation remains 0.46.0. It does not establish
model behavior, human reading/authorship, source authenticity, independent
execution, GPU behavior, sensitivity or scientific GO.

Regenerate from the repository root using the already installed dependencies:

```bash
python validation/2026-10-31-screen-adjudication/regenerate.py
```

The regenerator invokes `tools/ci_screen_adjudication.py`. Genuine native
fictional reports/captures go through prepare → explicitly synthetic fill →
apply. Temporary queues/preparation files are removed before receiving. Long
selected-text producer setup temporarily uses a wider CSV field setting and
restores it before the new no-CSV receiver. No captures, texts, sheets, keys or
entry records are committed here; the native temporary directory closes after
all children have joined.

`summary.json` records **24 positive API/CLI cases**, **46 adverse cases**, one
actual OS CLI raw-byte envelope check, original target/JUnit counts and **16
source hashes**. Counts are independently asserted by
`tests/test_ci_screen_adjudication.py`; detailed structure/boundary properties
are in `tests/test_screen_adjudication.py`.

Positive cases retain original N2/N3 order across zero/all/mixed/unresolved
declarations, missing and all-missing reports, declared-only receiving, zero
flags without an empty record, repeated hashes and long selected/unselected
text. Native flags/statistics and source completeness remain separate; missing
native counts stay null. Every requested JUnit has 3N+1 cases.

Adverse controls cover available hash/set/axis/both-arm contradictions,
pending-source common-scope mismatch, typed domains, closed roots, aliases and
paired sinks. Named work/additional-byte/output limits are deliberately lowered
in scoped controls and restored in `finally`; those controls prove enforcement,
not maximum-size throughput or a runtime bound. The pending 4097-probe capture
refuses before its native range reader. No test requests inference or network
model assets.

CLI values are actual in-process `main()` return codes, plus an actual child
process for raw stdout parity. API values record the native result's `exit_code`;
categorical `SavedScreenError` is mapped to harness 2 for adverse cases. The API
does not itself return an integer. This record is an editable-source profile;
original/rebuilt installed-package and hosted qualification are separate gates.

The [public contract](../../docs/screen-adjudication.md) states the encoded/work
limits, inherited native path/protocol disclosure and per-file replacement
semantics. Whole source consistency does not authenticate the supplied data or
turn operator declarations into human-verified native counts.
