# Annotation chunk prepare/collect: fictional command evidence

`functional.json` is generated by the actual CLI and library workflow from
`tools/ci_annotation_chunks.py`. It contains only aggregate counts, byte hashes,
declared attribution and fixed limits. Fresh native salts change hashes on
regeneration; this is not a byte-repeatability or human-labeling study.

Run on Windows with Python 3.12 and the project's locked CPU validation graph;
no models, GPU work, external annotation, inference or asset download occurs:

```bash
python tools/ci_annotation_chunks.py --checkout . --out NEW-functional.json
python -m pytest tests/test_annotation_chunks.py tests/test_ci_annotation_chunks.py -q
```

The helper creates a private synthetic native bound capture/key/template with
quoted multiline fictional completions, prepares all 18 rows into four parts,
explicitly manufactures fixture labels, collects a NEW full sheet, and invokes
unchanged schema-2 native ingestion. It separately extracts that actual sheet
and invokes the existing receipt-bound schema-3 consumer. The reported four
unusable judgments remain in the original 18-row population. A second API path
collects all-unusable labels and proves unchanged native calibration refuses an
empty measurement. Missing-part collection exits 2 with no output. Original
sheet/key bytes remain intact; private fixture files are removed when the helper
closes its native temporary-directory context.

Installed wheel and rebuilt-sdist CI include `test_ci_annotation_chunks.py`
inside the existing before/during/after package-origin guard. Until that exact
candidate CI completes, this record alone is local command/fixture evidence.
The tests prohibit inference and Hub resolution, check aggregate privacy canaries,
and exercise blankness, source/manifest/partition integrity, labels, bounds,
aliases, ordinary filesystem races and manifest-last partial publication.

No result here authenticates the source capture, annotator identity, independent
human judgments, genuine blinding, accuracy, sensitivity, safety or scientific
GO. Chunks are one population's partitions, not independent samples. No real
completion was shared and no new annotator permission is granted. Follow
`docs/data-handling-completions.md`, including the single named second-annotator
carve-out and terminal retention rule.
